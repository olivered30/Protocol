# NetMHC — netMHCpan 4.2c Python Wrapper

Interactive Python wrapper for **netMHCpan 4.2c** with GUI dialogs.
Designed for Spyder on macOS Apple Silicon (Darwin_arm64).

## Setup
```bash
git clone https://github.com/olivered30/Protocol.git
cd Protocol/NetMHC
pip install -r requirements.txt
```

## Usage
Edit `INSTALL_DIR` in `run_netmhcpan.py` to your netMHCpan path, then run it.
A dialog box will collect alleles, lengths, input mode and sequence.
